# Journal — Samedi 29 AOUT 2026 (rédigé par : ADOUFA Koffi Eben-Ezer) #
1. Contenu de la formation
Brainstorming sur les projets

Nous avons parcouru et évalué la faisabilité des 150 projets intégrateurs proposés. À l’issue de cette analyse, le groupe a retenu le projet :

« Balance électronique connectée à enregistrement de données »

Ce projet a été retenu en remplacement du projet « Pompe solaire pilotée (P152) », jugé trop vague par le formateur.

Présentation et défense du projet

Nous avons ensuite présenté et défendu le projet Balance électronique connectée à enregistrement de données, en précisant sa problématique, son fonctionnement, ses exigences techniques et fonctionnelles, les procédés de fabrication ainsi que les composants nécessaires.

2. Acquis / Ce que j’ai appris

J’ai appris à mieux définir les contours d’un projet à travers l’élaboration d’un cahier des charges comprenant :

a. Objet du projet

Le projet vise à concevoir une balance électronique connectée et à mémoire d’enregistrement, destinée notamment à pallier le manque d’équipements de mesure dans les établissements scolaires et à constituer un historique de données utilisable pour la gestion des laboratoires et le pilotage pédagogique.

b. Problématique

L’objectif est de concevoir une balance capable de :

mesurer la masse des objets ;
afficher localement les résultats ;
associer un nom et une description à chaque mesure ;
enregistrer les données localement ;
transmettre les données vers une base consultable à distance.
c. Fonctionnement du système

Le système repose principalement sur une carte XIAO ESP32S3 reliée à une cellule de charge + module HX711.

Le fonctionnement retenu est le suivant :

La cellule de charge mesure la masse déposée sur le plateau.
La XIAO ESP32S3 récupère et traite la mesure.
Le résultat est affiché sur un écran OLED local de 0,96 pouce.
Sur demande, une interface web locale permet de saisir le nom et la description associés à la mesure.
Après validation, les données sont enregistrées sur une carte micro-SD.
En parallèle, les données sont transmises par Wi-Fi et requête HTTP à un Google Apps Script, puis enregistrées dans une feuille Google Sheets.
d. Exigences principales

La balance doit notamment :

mesurer des objets de 0 à 2 kg ;
afficher le résultat localement ;
permettre la saisie d’un nom et d’une description ;
enregistrer les mesures sur micro-SD ;
transmettre les données vers Google Sheets ;
proposer une interface web accessible depuis un téléphone ou un ordinateur connecté au même réseau ;
fonctionner localement sans Internet pour la mesure et l’enregistrement local ;
être réalisée avec une XIAO ESP32S3 programmée en MicroPython via mBlock ;
mobiliser au moins trois procédés de fabrication ;
être réalisable au FabLab dans le délai prévu ;
respecter un budget indicatif maximal de 60 000 FCFA.
e. Procédés de fabrication

Trois procédés principaux ont été retenus :

Impression 3D : boîtier et supports internes ;
Découpe laser : plateau de pesée et éléments de structure ;
Assemblage électronique : soudure, câblage et intégration des différents modules.
f. Principaux composants

Les composants identifiés sont :

XIAO ESP32S3 ;
cellule de charge 10 kg + HX711 ;
lecteur/écriture micro-SD ;
écran OLED 0,96 pouce ;
batterie Li-Po rechargeable et module de charge ;
plateau de pesée ;
filament PLA pour le boîtier ;
câblage, connecteurs et boutons poussoirs ;
visserie et fixations ;
interrupteur marche/arrêt et bouton tare.
g. Planning

Le cahier des charges, la fiche projet et la liste des composants constituent la base de travail.

Le développement du code doit commencer à partir du jour suivant, notamment pour :

la lecture du capteur ;
le serveur web local ;
l’écriture sur micro-SD ;
l’envoi des données vers Google Apps Script.

Le projet doit être réalisé dans le délai global de trois semaines imparti par le FabLab.
